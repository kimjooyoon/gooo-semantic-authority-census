# Semantic authority census protocol v1

## Claim boundary

The census observes whether a fixed semantic obligation is bound through Gooo source, semantic IR, and a generated-Go marker. It does not infer product utility and does not turn a bootstrap implementation into self-hosting.

## Fixed denominator

The denominator is exactly twelve cells. FOUNDATION, COHERENCE, and REGRESSION contain four cells each. DRIVER, OUTCOME, and GUARDRAIL contain four cells each. Every cell has one Gooo meta activity.

Decision precedence is REFUTED, then UNKNOWN, then CLOSED.

UNKNOWN always preserves stage, step, reason, unknown_class, next_operation, and blocked_by. A direct missing input has an empty blocked_by array. A known contradiction or forbidden authority is REFUTED.

## Exact paired observation

The corpus uses the same three obligations before and after.

- generated-bound: 2 -> 3
- handwritten Go: 1 -> 0

The pair demonstrates the census and a bounded fixture migration. It is not a percentage and does not establish repository-wide improvement.

## Bootstrap boundary

The policy compiler and census evaluator are handwritten Go. The Gooo policy controls the twelve cells, proof and indicator partitions, precedence, UNKNOWN schema, and generated policy artifact. The report therefore keeps core_semantic_authority_closed=false.

## Authority

All generated policy, reports, test logs, time observations, and RSS observations are written beneath a caller-owned CI temporary directory. Repository-write authority, local test execution, infrastructure mutation, provider installation, and network mutation are zero.
